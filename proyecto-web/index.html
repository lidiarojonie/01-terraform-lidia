01 / El kit de trabajo

Tres piezas, una misma dirección.

Las herramientas cumplen papeles distintos, pero juntas hacen que publicar sea repetible, comprensible y rápido.

⌘01

Terraform

Terraform describe la infraestructura con archivos de configuración. Así podemos crear y repetir recursos de AWS sin configurarlos manualmente uno a uno.

resource "aws_s3_bucket"
◈02

Amazon S3

Amazon S3 es un servicio de almacenamiento de objetos. En esta práctica guarda los archivos de la web y los sirve para que puedan visitarse desde internet.

bucket / proyecto-web
✦03

MCP

Model Context Protocol es un estándar que permite a un asistente de IA conectar con herramientas y contexto de forma estructurada, con más utilidad y control.

context → acción asistida
